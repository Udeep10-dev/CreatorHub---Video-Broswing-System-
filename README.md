📌 C Hub – Online Video Browsing System

C Hub is a Java-based Online Video Browsing System developed as a Year 2 Semester 1 OOP group project at the Sri Lanka Institute of Information Technology (SLIIT) – Malabe.
This application allows users to browse, search, watch, upload, and manage videos, including newly released movies. The system demonstrates key Object-Oriented Programming (OOP) concepts while offering a user-friendly interface.

🛠 Technologies Used

Backend
Java (Core OOP Implementation)

Frontend

HTML
CSS
JavaScript

💡 Key Features

🔐 User Authentication & Profile Management

Secure login & logout
Session handling
Update profile details (name, email, phone)
Upload/change profile picture

🎬 Video Browsing & Search

Browse videos and movies by categories
Search using keywords
Filter and sort results
Preview videos before watching

▶️ Watch & Upload Videos

Watch videos via an embedded video player
Upload videos as a content creator
Add thumbnails and video metadata

🗂 Video Management

Delete uploaded videos
Edit video details
Content moderation for policy compliance

🔒 System Security & Administration

Monitor user activity
Manage platform settings
Review user complaints & reports
Ensure video policy compliance

📁 Project Modules (OOP Concepts)

Encapsulation for user authentication
Inheritance for different user roles (User, Creator, Admin)
Polymorphism for handling video and movie objects
Abstraction for backend processing

👥 Team Project

This system was built collaboratively as part of the Object-Oriented Programming (OOP) module.
